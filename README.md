# 📚 Book Library

A simple and beginner-friendly Book Library web interface developed using HTML and CSS.

## 📖 About the Project

Book Library is a basic front-end web development project designed to display books in a simple library-style layout. It provides a clean interface where users can browse sample books, view prices and availability, and see a library registration section.

## ✨ Features

- Simple Book Library homepage
- Navigation section for Browse, Genres, and My Shelf
- Book cards with titles and prices
- Book availability information
- Save/Favourite buttons (UI only)
- Library registration section (UI only)
- Custom styling using CSS

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
book-library/
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the Book Library interface.
